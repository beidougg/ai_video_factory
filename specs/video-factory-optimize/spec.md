## 1. Problem Statement

现有 AI Video Factory 管线已跑通端到端（创意 → 脚本 → 配音 → 渲染 → 质检 → 成片），但对比 2026 年抖音生态的 AI 短视频主流做法，存在六个可量化的差距：

**画面比例不适配。** 当前唯一模板为 16:9 横屏（1920x1080），而抖音/快手主流消费形态是 9:16 竖屏。2025 年 3 月至 11 月抖音 AI 内容投稿量增长 185%，优质 AI 内容投稿量飙升 1430%，其中竖屏内容占据绝对主导。横屏成片发抖音会显著拉低完播率与推荐权重。

**缺少背景音乐。** 当前成片只有配音轨道，无 BGM。同类开源工具 MoneyPrinterTurbo 已内置 BGM 混音（音量压至语音 30% 以下），观感差距明显。

**字幕时间轴精度不足。** 当前 VTT 按句均分时间戳，但中文朗读每字时长不等，导致"声画不同步"。主流做法已升级为 word-level 逐字时间戳对齐。

**选题缺少热点参照。** 当前选题分析由 LLM 纯生成，不参考平台热门趋势。抖音内置"边刷边做"功能会先分析热门视频的风格、运镜、节奏，再生成参考方向，试错成本极低。

**脚本结构约束不强制。** 当前脚本生成虽有"钩子"字段，但未强制"钩子-反差-干货-行动"四段式结构，爆款基因不稳定。

**素材来源单一。** 当前素材检索仅依赖本地素材库。同类工具已接入 Pexels/Pixabay 无版权素材 API，素材命中率更高。

**目标：** 通过六项适配优化，让系统产出的视频在抖音/快手生态具备竞争力，端到端生产时间与成本不显著上升。

## 2. Success Metrics

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 竖屏渲染支持 | 9:16 与 16:9 双模板可选 | 渲染命令参数切换 + ffprobe 分辨率验证 |
| BGM 混音 | 100% 成片包含 BGM，音量 ≤ 语音 30% | 混音后 ffprobe 音频响度检测 + 人工抽听 |
| 字幕同步精度 | 逐字时间戳覆盖率 100%，无 >200ms 偏移 | VTT 时间戳与 TTS 词级数据比对 |
| 选题热点参照 | ≥ 1 个热点数据源接入（如抖音热榜） | 选题分析报告中包含热点来源引用 |
| 脚本结构合规率 | ≥ 90% 脚本命中四段式结构 | 脚本 JSON 结构校验 |
| 素材命中率提升 | 本地库 + 外部素材源合并命中率 ≥ 85% | 审阅"通过"率统计 |
| 端到端成本增量 | 每条视频新增成本 ≤ ¥0.5 | API 账单对比 |

## 3. User Stories

| # | 角色 | 场景 | 期望结果 |
|---|------|------|----------|
| US-1 | 内容创作者 | 我想把视频发到抖音 | 系统能生成 9:16 竖屏成片，观感与抖音原生内容一致 |
| US-2 | 内容创作者 | 我想让视频更有氛围感 | 成片自动配 BGM，音量不压人声 |
| US-3 | 内容创作者 | 我刷到一条热门视频想借鉴 | 系统选题阶段参考热点趋势，给出类似方向的创意建议 |
| US-4 | 内容创作者 | 我想保证字幕和配音同步 | 字幕按逐字时间戳渲染，不出现声画错位 |
| US-5 | 运营者 | 我的脚本总是不爆 | 系统强制四段式结构，保证钩子-反差-干货-CTA 完整 |
| US-6 | 内容创作者 | 我的本地素材不够用 | 系统能自动从免费素材源补充候选画面 |

## 4. Acceptance Criteria

### AC-1: 竖屏 9:16 模板（高优先级）

- 新增 9:16（1080x1920）渲染模板，与现有 16:9 模板并存。
- 渲染管线通过 `template` 参数选择模板，默认仍为 16:9 或可配置。
- 竖屏模板支持：字幕、配音、分镜文字动画全部适配竖屏布局。
- ffprobe 验证输出分辨率 1080x1920，无黑边、无拉伸。

### AC-2: 背景音乐（高优先级）

- 内置 BGM 素材库（≥ 5 首，免费可商用），支持自定义 BGM 文件。
- 混音规则：BGM 音量 ≤ 人声 30%，人声清晰可辨。
- 支持淡入淡出，BGM 时长自动适配视频时长（不足循环、超出截断）。
- 渲染管线输出含 BGM 的最终 MP4。

### AC-3: 逐字时间戳字幕（高优先级）

- TTS 阶段采集 word-level 时间戳数据，替代当前句级均分。
- VTT 生成基于逐字时间戳聚合为字幕行（每行 ≤ 15 字，显示 ≥ 2 秒）。
- 字幕时间轴与配音对齐误差 ≤ 200ms。

### AC-4: 选题热点参照（中优先级）

- 接入至少一个免费热点数据源（抖音热榜 / 微博热搜 / 百度指数之一）。
- 选题分析调用 LLM 时注入热点参考，输出报告含"热点契合度"字段。
- 热点源不可用时降级为纯 LLM 分析，不阻断管线。

### AC-5: 脚本四段式结构（中优先级）

- 脚本生成 Prompt 强制"钩子(0-3s) - 反差(3-10s) - 干货(10s-结束前) - CTA(结尾)"四段结构。
- 每个分镜标记所属段落，脚本 JSON 结构校验器在生成后自动校验。
- 校验失败自动重试一次（带纠错提示）。

### AC-6: 免费素材源接入（中优先级）

- 接入 Pexels 或 Pixabay 免费素材 API（需注册免费 key）。
- 素材检索：本地库命中优先，本地缺失时回退外部素材源。
- 外部素材下载失败时降级为现有渐变背景渲染，不阻断管线。

## 5. Non-Goals

| 不做 | 原因 |
|------|------|
| 文生视频（即梦 Seedance 等）接入 | 依赖第三方积分与效果不稳定，成本不可控；本 spec 聚焦现有管线适配优化，文生视频作为独立后续迭代评估 |
| AI 数字人出镜 | 属于账号人设运营范畴，与本系统生产管线解耦 |
| 抖音自动发布 | 抖音无对普通开发者开放的发布 API，非代码可解决 |
| 爆款模仿（边刷边做） | 涉及热门视频内容抓取与二次创作，版权风险高，仅做热点趋势参考 |
| 多语言 BGM 曲库 | 聚焦中文内容生态 |
| 素材库自动化标签系统 | 现有标签体系可用，本期只补外部素材源 |

## 6. Constraints

### 技术约束

| 约束项 | 说明 |
|--------|------|
| 运行环境 | Windows 10/11，无 GPU |
| 渲染引擎 | Remotion（Node.js ≥ 18）+ FFmpeg（≥ 5.0），与现有管线一致 |
| 主力 LLM | DeepSeek V3（兼容 OpenAI 接口），沿用现有调用封装 |
| TTS | edge-tts（免费），需确认 word-level 时间戳能力，否则改用豆包语音（可选） |
| BGM 来源 | 免费可商用素材（如 Pixabay Music），需本地缓存 |
| 热点数据源 | 免费 API 或公开页面抓取，需处理频率限制 |

### 资源约束

| 约束项 | 说明 |
|--------|------|
| 素材库根目录 | `e:\ai_video_factory\`（与基础架构一致） |
| API 月预算 | 新增外部 API 费用 ≤ ¥10/月（免费层优先） |
| 兼容性 | 不破坏现有 7 步管线与四个审阅点，优化为增量接入 |
